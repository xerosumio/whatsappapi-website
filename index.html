Developer-Friendly API

Our comprehensive API gives you complete control over WhatsApp messaging:

// Send a WhatsApp message
fetch('/api/send', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    to: "1234567890@c.us",
    message: "Hello world!"
  })
})
.then(response => response.json())
.then(data => console.log("Message sent:", data));
